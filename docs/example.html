Read the trade-off correctly

Cards summarize the configured experiment; the alignment and votes show its first query. Seed recall counts shared selected anchors divided by all exact k-mers surviving at the true position. It is undefined when none survive. Mapping recall measures whether the known start has a candidate, before any mismatch threshold. High seed recall and high mapping recall are different objectives.

Index bytes count sorted keys, offsets and positions, excluding extraction buffers, allocator metadata and build scratch space. Both index variants use the same layout. Selector timings use the same precomputed fingerprints, one warm-up and the median of measured runs. Query timings are totals; oracle checks are excluded.
